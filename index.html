How one iteration works

The loop is deliberately small: the model never touches the browser, and the browser never talks to the model. A snapshot goes in, one JSON action comes out, Playwright performs it, and the frame is saved before the next iteration.

01 · input
Task + URL
CLI flag or the form on this page. Optional step cap and time budget.
02 · observe
Page snapshot
Visible text plus a numbered list of interactive elements with stable [data-pba-idx] selectors.
03 · plan
Pollinations legacy API
POST text.pollinations.ai/openai returns exactly one action as JSON.
04 · act
Playwright
click / type / press / select / scroll / goto / extract — sandboxed, headless, time-boxed.
05 · prove
Screenshot
Saved as runs/<id>/NN-action.png and appended to steps.json.

Run it yourself

Node 20+, no API key. The Classic API is free and rate limited per IP, so calls are queued with a minimum gap and a 402 Retry-After is respected.

# 1. install npm install npx playwright install chromium # skip if chromium is already on PATH # 2. one run from the CLI node src/cli.js \ --task "Search for 'notebook' and report the price" \ --url http://localhost:5173/demo/site/index.html \ --max-steps 5 --budget-ms 240000 # 3. or the console + API npm start # http://localhost:5173

Endpoints used

Legacy (Classic) Pollinations API — deprecated upstream in favour of gen.pollinations.ai, still reachable and used here on purpose.

POST /openaitext.pollinations.ai — OpenAI-compatible chat, used as the planner
GET /{prompt}text.pollinations.ai — simple prompt variant, available in the client
GET /modelstext.pollinations.ai — model discovery
GET /prompt/{p}image.pollinations.ai — legacy image generation, for step banners
POST /api/runlocal server — start a run { task, startUrl, maxSteps }
GET /api/runslocal server — every run with its steps and screenshots
